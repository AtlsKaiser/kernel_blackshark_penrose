## 黑鲨4 内核源码

- 基于 **Arrow 13**，内核版本由 **4.19.157** 升级为 **4.19.325**
- Arrow13 仓库地址：https://github.com/Edward-Projects/kernel_blackshark_penrose
- Arrow13 上游仓库（Arrow13 fork 自该仓库）：https://github.com/DtHnAme/kernel_blackshark_penrose
- 本仓库基于 Arrow13 拉取后自行维护，并将内核升级至 4.19.325
- 构建脚本为内核源码根目录 `build.sh`
- Clang 使用 **ZyC-Clang**，仓库地址：https://github.com/ZyCromerZ/Clang
- 默认开启 **KSU**，KSU 分支为 **BACKSLASHXX-KSU**
- 如需切换或移除 KSU，请自行修改 `build.sh` 和配置文件
- 本仓库**不提供任何 AnyKernel 压缩文件**

## Black Shark 4 Kernel Source

- Based on **Arrow 13**, kernel upgraded from **4.19.157** to **4.19.325**
- Arrow13 repository: https://github.com/Edward-Projects/kernel_blackshark_penrose
- Arrow13 upstream repository (Arrow13 was forked from it): https://github.com/DtHnAme/kernel_blackshark_penrose
- This repository is based on a pulled copy of Arrow13, maintained independently, with the kernel upgraded to 4.19.325
- Build script: `build.sh` in the kernel source root directory
- Clang: **ZyC-Clang**, repository: https://github.com/ZyCromerZ/Clang
- **KSU** enabled by default, KSU branch: **BACKSLASHXX-KSU**
- To switch or remove KSU, modify `build.sh` and the config files yourself
- This repository **does not provide any AnyKernel zip**
